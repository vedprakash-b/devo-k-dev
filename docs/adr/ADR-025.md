# ADR-025: Agent names follow the Hindu pantheon's order

- **Status:** Accepted
- **Date:** 2026-10-15
- **Deciders:** Ved (owner), Claude (proposer)

## Decision

Agent names follow the Hindu pantheon's order; goddesses in every tier; line icons, not images of deities.

## Why

A memorable, coherent theme that stays respectful.

## Revisit if

Ved changes any name.
