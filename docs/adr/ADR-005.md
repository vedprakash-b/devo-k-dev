# ADR-005: PostgreSQL with pgvector for state

- **Status:** Accepted
- **Date:** 2026-10-13
- **Deciders:** Ved (owner), Claude (proposer)

## Decision

PostgreSQL with pgvector for state; Redis for counters and events; Temporal keeps its own store.

## Why

Few moving parts.

## Revisit if

Throughput becomes a bottleneck.
