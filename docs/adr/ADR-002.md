# ADR-002: Develop inside WSL2 with Docker Desktop

- **Status:** Accepted
- **Date:** 2026-10-13
- **Deciders:** Ved (owner), Claude (proposer)

## Decision

Develop inside WSL2 with Docker Desktop.

## Why

Sandboxes are Linux containers; parity with production.

## Revisit if

WSL2 file or memory performance hurts.
