# ADR-001: Standalone Python system, not built on Copilot or Claude Code runtimes

- **Status:** Accepted
- **Date:** 2026-10-13
- **Deciders:** Ved (owner), Claude (proposer)

## Decision

Standalone Python system, not built on Copilot or Claude Code runtimes.

## Why

The portfolio must show engineering, not configuration.

## Revisit if

Never for the core.
