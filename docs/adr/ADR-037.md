# ADR-037: Supply chain: Actions and pre-commit hooks pinned to commit SHAs, images to exact tags, gitleaks binary checksum-verified, uv.lock with hashes, pip-audit in CI

- **Status:** Proposed
- **Date:** 2026-10-22
- **Deciders:** Ved (owner), Claude (proposer)

## Decision

Supply chain: Actions and pre-commit hooks pinned to commit SHAs, images to exact tags, gitleaks binary checksum-verified, uv.lock with hashes, pip-audit in CI.

## Why

A compromised tag or package cannot silently change what CI runs (the LiteLLM lesson).

## Revisit if

Pin maintenance costs more than it saves; then add Dependabot or Renovate.
