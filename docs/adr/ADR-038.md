# ADR-038: CI runs integration tests against the real Compose stack, plus `devokdev doctor`, on every pull request

- **Status:** Proposed
- **Date:** 2026-10-22
- **Deciders:** Ved (owner), Claude (proposer)

## Decision

CI runs integration tests against the real Compose stack, plus `devokdev doctor`, on every pull request.

## Why

Proves the stack and the code work together on a clean machine, not just on Ved's laptop.

## Revisit if

CI time grows past about 10 minutes.
