# ADR-045: The fitness code-fix probe runs model-written code only in a throwaway Docker container with ADR-007's hardening flags

- **Status:** Proposed
- **Date:** 2026-10-26
- **Deciders:** Ved

## Decision

The fitness code-fix probe runs model-written code only in a throwaway Docker container with ADR-007's hardening flags.

## Why

Model-written code must never run on the host (ADR-007), even before M2's full sandbox exists. If Docker is unavailable the probe is skipped, not run unsafely.

## Revisit if

M2's sandbox replaces it.

## Details

Flags: no network, read-only root, tmpfs /tmp, all capabilities dropped, no-new-privileges, user 65534, 256 MB memory, half a CPU, 64 processes, a time limit, image pinned to an exact tag. See `src/devokdev/fitness/sandbox.py` and `tests/integration/test_sandbox.py`. The walkthrough with alternatives and trade-offs is in [`docs/learning/M1.md`](../learning/M1.md).
