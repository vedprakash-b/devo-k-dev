# ADR-028: Model fitness profiles and a pre-flight verdict before plan approval

- **Status:** Proposed
- **Date:** 2026-10-15
- **Deciders:** Ved

## Decision

Model fitness profiles and a pre-flight verdict before plan approval.

## Why

Know before starting whether the models can do the job.

## Revisit if

Probes stop predicting run outcomes.

## Details

M1 builds the profiles (`src/devokdev/fitness/`, `devokdev models profile`). The pre-flight verdict at plan approval arrives with the Orchestrator in M3. The walkthrough is in [`docs/learning/M1.md`](../learning/M1.md).
