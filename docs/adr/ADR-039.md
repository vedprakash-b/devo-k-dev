# ADR-039: The showcase demo job is a small new web app; bug-fix jobs serve as the automated benchmark

- **Status:** Accepted
- **Date:** 2026-10-22
- **Deciders:** Ved

## Decision

The showcase demo job is a small new web app (a habit tracker with login); bug-fix jobs serve as the automated benchmark.

## Why

A new app uses the most roles and produces something visual for the README demo.

## Revisit if

Free quota cannot finish the app in one run.

## Details

The three-minute README demo is built around this job; the bug-fix benchmark arrives with the evals in M8.
