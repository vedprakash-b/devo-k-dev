# ADR-042: Quota is tracked as reservable windows in Redis, reserved atomically by Lua scripts before each call, settled after, and overwritten by provider headers

- **Status:** Proposed
- **Date:** 2026-10-26
- **Deciders:** Ved

## Decision

Quota is tracked as reservable windows in Redis, reserved atomically by Lua scripts before each call, settled after, and overwritten by provider headers.

## Why

Free-tier limits are windows (per minute, per day), so mirroring them is simplest; reserving before the call is what keeps concurrent agents from overspending; Lua makes check-and-take atomic; the provider's headers are the source of truth.

## Revisit if

A provider's limits cannot be expressed as windows (for example Cloudflare's neurons), or Redis round-trips become a bottleneck.

## Details

Refines the design's "Redis token buckets". One contract test suite runs on both the in-memory and the Redis implementation. See `src/devokdev/router/state.py` and `redis_state.py`. The walkthrough with alternatives and trade-offs is in [`docs/learning/M1.md`](../learning/M1.md).
