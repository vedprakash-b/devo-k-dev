# ADR-044: Fitness profiles are cached as one JSON file per model in a git-ignored data directory, not in PostgreSQL

- **Status:** Proposed
- **Date:** 2026-10-26
- **Deciders:** Ved

## Decision

Fitness profiles are cached as one JSON file per model in a git-ignored data directory, not in PostgreSQL.

## Why

A profile is a recomputable cache; files need no schema or migration tool yet, are easy to read and delete, and work without the stack running.

## Revisit if

The pre-flight check (M3) needs to query profiles alongside plans, or profiles must be shared between machines.

## Details

See `src/devokdev/fitness/profile.py`; the directory is `DEVOKDEV_DATA_DIR`, `.devokdev/` by default. The walkthrough with alternatives and trade-offs is in [`docs/learning/M1.md`](../learning/M1.md).
