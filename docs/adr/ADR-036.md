# ADR-036: M0 runs Temporal's CLI development server (in-memory) in Docker Compose

- **Status:** Proposed
- **Date:** 2026-10-22
- **Deciders:** Ved (owner), Claude (proposer)

## Decision

M0 runs Temporal's CLI development server (in-memory) in Docker Compose.

## Why

One container, built-in Web UI, nothing to configure; workflow history is disposable while nothing real runs.

## Revisit if

Runs must survive a stack restart (by M4 at the latest): move to start-dev with a persistent database file or Temporal on PostgreSQL.

The full context, alternatives and trade-offs are in [`docs/DESIGN.md`](../DESIGN.md) (Decision log and the section the decision belongs to).
