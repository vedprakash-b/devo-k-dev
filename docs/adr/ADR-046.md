# ADR-046: Roles map to five role classes (reasoning, coding, review, vision, light); models carry a quality tier per class

- **Status:** Proposed
- **Date:** 2026-10-26
- **Deciders:** Ved

## Decision

Roles map to five role classes (reasoning, coding, review, vision, light); models carry a quality tier per class.

## Why

Nineteen roles share a handful of skill profiles. A tier per class keeps `models.yaml` small and makes adding a role one line. Per-role needs (tools, vision, minimum context, a different model family from the author) stay on the role.

## Revisit if

Measured results show roles in the same class need different models.

## Details

See `config/models.yaml` (`roles:`) and `src/devokdev/llm/registry.py`. The walkthrough with alternatives and trade-offs is in [`docs/learning/M1.md`](../learning/M1.md).
