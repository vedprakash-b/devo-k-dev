# ADR-032: The repo carries AGENTS.md and a Copilot pointer file for coding agents

- **Status:** Accepted
- **Date:** 2026-10-15
- **Deciders:** Ved

## Decision

The repo carries AGENTS.md and a Copilot pointer file for coding agents.

## Why

Any coding agent working in the repo gets the same commands, conventions and rules.

## Revisit if

Coding agents adopt another standard.

## Details

`AGENTS.md` at the root; `.github/copilot-instructions.md` points to it.
