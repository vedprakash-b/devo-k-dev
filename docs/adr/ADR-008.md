# ADR-008: Free and open-weight models only; no private or employer code to endpoints that train on prompts

- **Status:** Proposed
- **Date:** 2026-10-13
- **Deciders:** Ved

## Decision

Free and open-weight models only; no private or employer code to endpoints that train on prompts.

## Why

Zero cost; data protection.

## Revisit if

A paid budget appears.

## Details

Put into effect in M1: every provider and model in `config/models.yaml` has `trains_on_prompts`, which defaults to true when unknown, and the routing policy excludes such models whenever a session is marked `private_data`. The walkthrough is in [`docs/learning/M1.md`](../learning/M1.md).
