# ADR-004: Our own gateway and router over OpenAI-compatible APIs instead of LiteLLM

- **Status:** Proposed
- **Date:** 2026-10-13
- **Deciders:** Ved

## Decision

Our own gateway and router over OpenAI-compatible APIs instead of LiteLLM.

## Why

Routing is a core feature of the project; the key-holding layer stays dependency-light after the March 2026 LiteLLM compromise.

## Revisit if

Many needed providers lack OpenAI-compatible APIs.

## Details

Put into effect in M1: `src/devokdev/llm/` and `src/devokdev/router/`. ADR-041 records how the adapter talks HTTP. The walkthrough is in [`docs/learning/M1.md`](../learning/M1.md).
