# ADR-007: Hardened Docker sandbox, no network and no secrets by default

- **Status:** Accepted
- **Date:** 2026-10-13
- **Deciders:** Ved (owner), Claude (proposer)

## Decision

Hardened Docker sandbox, no network and no secrets by default.

## Why

Strong isolation without paid services.

## Revisit if

Devo-K-Dev ever runs untrusted users' jobs.
